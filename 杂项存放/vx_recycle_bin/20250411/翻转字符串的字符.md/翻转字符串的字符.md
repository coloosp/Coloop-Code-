# 翻转字符串的字符
[翻转字符串的字符](https://www.lanqiao.cn/problems/250/learning/?page=1&first_category_id=1&name=字符串)

```
#include <iostream>
#include <string>
using namespace std;
int main()
{
  string s;
  getline(cin,s);
  for(int i=0,j=s.size()-1;i<j;i++,j--){
    swap(s[i],s[j]);
  }
  cout <<s<<endl;


  return 0;
}
```
## 解析
普通的翻转字符串，但是要注意，正常的cin会在空格处停止，如果不想要这样做的话，使用getline（）来完成
