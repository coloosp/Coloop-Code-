# 模板
 ## 概念
**模板**： 是一种泛型编程技术，允许你编写可以处理多种类型的数据的代码，而不需要为每种类型重复编写相同的功能。

## 函数模板
**语法**：
```
template <typename T>
返回类型 函数名(参数列表) {
    // 函数体
}
```
* template:声明创建模板
* typename：表明后面是一种数据类型，也可以用class替换
* T：通用的数据类型，名称也可以替换，通常使用T

**实例**：使用函数模板解决两数交换问题
1. 函数模板定义  
```
#include <iostream>

// 定义函数模板 swap
template <typename T>
void swap(T &a, T &b) {
    T temp = a;
    a = b;
    b = temp;
}
```
2. 使用自动类型推导  
```
int main() {
    int x = 5, y = 10;
    double a = 3.14, b = 2.71;

    // 使用自动类型推导交换整数
    swap(x, y);

    // 使用自动类型推导交换浮点数
    swap(a, b);

    return 0;
}
```
3.使用显式指定类型
```
int main() {
    int m = 15, n = 20;
    double p = 1.41, q = 1.73;

    // 显式指定类型交换整数
    swap<int>(m, n);

    // 显式指定类型交换浮点数
    swap<double>(p, q);

    return 0;
}
```

**注意**：
1. 自动类型推导，必须推导出一致的数据类型T，才可以使用
2. 模板必须确定出T的数据类型，才可以使用

## 普通函数与模板函数的区别
1. 普通函数调用时可以发生自动类型转换(隐式类型转换)  
例如字符型可以转换成整型的ascll码
2.函数模板调用时，如果使用自动类型推动，则不会发生隐式类型转换
3.如果利用显示制定类型的方式，可以发生隐式类型转换

## 普通函数与函数模板的调用规则
* 如果普通函数和函数模板都可以实现，优先调用普通函数
* 可以通过空模板参数强制调用函数模板
* 函数模板也可以发生函数重载
* 如果函数模板可以产生更好的匹配，优先调用函数模板  

注意：提供函数模板时，最好不要提供普通函数，以免出现二义性（吃饱了不是）

## 函数模板的局限与解决
**局限性**：函数模板确实可以识别大部分数据类型，但是但对于一些例如自定义数据类型（类与结构体），函数模板往往无法识别

**解决**：针对以上问题，有三种解决方案
1. 重载运算符，来实现特定数据类型比较的可能
2. 模板特化  ：如果自定义类型的行为与默认模板行为不同，可以通过模板特化来提供专门的实现。
```
// 泛型模板
template <typename T>
void swap(T &a, T &b) {
    T temp = a;
    a = b;
    b = temp;
}

// 特化模板以处理 MyClass 类型
template <>
void swap<MyClass>(MyClass &a, MyClass &b) {
    int temp = a.value;
    a.value = b.value;
    b.value = temp;
}
```
3. 友元函数  ：可以通过友元函数来允许模板访问自定义类型的私有成员。  
```
class MyClass {
private:
    int value;

public:
    MyClass(int v) : value(v) {}

    // 声明友元函数
    template <typename T>
    friend void swap(T &a, T &b);
};

// 定义友元函数
template <typename T>
void swap(T &a, T &b) {
    T temp = a;
    a = b;
    b = temp;
}
```

## 类模板
作用：建立一个通用类，类中的成员数据类型可以不具体规定，用一个虚拟的类型来代表

语法：
`template <typename T>
类`

示例：
```
#include <iostream>
#include <string>

// 定义一个模板类 Person
template <typename NameType, typename AgeType>
class Person {
public:
    // 构造函数
    Person(NameType name, AgeType age) : name(name), age(age) {}

    // 获取名字
    NameType getName() { return name; }

    // 设置名字
    void setName(NameType name) { this->name = name; }

    // 获取年龄
    AgeType getAge() { return age; }

    // 设置年龄
    void setAge(AgeType age) { this->age = age; }

private:
    NameType name; // 名字
    AgeType age;   // 年龄
};

// 使用模板类的示例
int main() {
    // 创建一个 Person 实例，名字为 std::string 类型，年龄为 int 类型
    Person<std::string, int> person("Alice", 30);
    std::cout << "Name: " << person.getName() << ", Age: " << person.getAge() << std::endl;

    // 修改名字和年龄
    person.setName("Bob");
    person.setAge(25);
    std::cout << "Name: " << person.getName() << ", Age: " << person.getAge() << std::endl;

    return 0;
}
```

## 类模板与函数模板的区别
1. 类模板没有自动类型推导的使用方式
2. 类模板在模板参数列表中可以有默认参数

## 类模板中成员函数的创建时机
类模板中的成员函数与普通类中的成员函数创建时机存在区别：
* 普通类中的成员函数一开始就可以创建
* 类模板中的成员函数在调用时才创建


## 类模板对象做函数参数

使用类模板创建出来的对象可能会在另一个函数里面需要作为参数，存在以下三种传入方式：
* 指定传入的类型——直接显示出对象的数据类型
* 参数模板化——将对象中的参数变为模板传入
* 整个类模板化——将这个对象的类的数据类型模板化进行传递

**注意**：比较泛用的是第一种传入方式—指定传入的类型，更直接明了

## 模板与继承
当需要继承类模板时需要注意：
1. 当子类继承父类是一个类模板时，子类在声明时需要制定出父类T的类型
2. 如果想灵活指定出父类中T的内容，子类也可以变成类模板

## 类模版的分文件编写
**问题**：在面向对象的思想中，我们一般把声明作为头文件，实现作为源文件，再使用另一个源文件调用。
但是，对于类模板来说，如果这样做，将会编译失败，因为类模板的成员函数创建是在调用阶段，导致如果份文件编写链接不到实现函数部分

**解决**：
1. 将调用部分包含实现部分的cpp源文件
2. 将声明和实现写在同一个文件里面，并更改为.hpp文件，hpp是一个约定的名称，不强制要求
